# Address Book Management System

## Overview

A console-based Address Book Management System developed in C. The application allows users to store and manage contact information efficiently using structures and file handling.

## Features

- Add Contact
- Search Contact
- Edit Contact
- Delete Contact
- Display all contacts
- Save Contacts to File
- Load Contacts from File

## Technologies Used

- C Programming
- Structures
- File Handling
- Modular Programming
